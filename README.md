# ケータイ打ち検定

**あの頃の親指、まだ動く？**
ガラケーの「ケータイ打ち（トグル入力）」で平成のメールを5通打つタイムアタック。送信までのタイムで「あなたの親指は◯◯年製」を判定します。

公開URL: https://knnnt.github.io/keitai-uchi/

## 遊び方

- 画面下のキーパッドで、お題のメールをそのまま打つ（例：［1］を3回で「う」）。
- 同じキーの文字が続く時は［→］（十字キー）で確定。1.2秒何も押さなくても確定します。
- ［＊］で直前の文字に ゛→゜→小文字 を順につける（は→ば→ぱ→は、つ→っ→づ→つ）。
- ［＃］で 、。？！… を切り替え。［0］は「わをんー」。
- 間違えたら［クリア］で1字消す。わからない時は［ヒント］で打ち方を表示。
- 5通送ると判定結果のメールが届きます。Xへのポストと、結果カード画像（1200x630）の保存ができます。
- PCはキーボードでも遊べます：数字キー／テンキー、`*` か `.` ＝＊、`#` か `/` ＝＃、`→` か `Enter` ＝確定、`BackSpace` ＝クリア、`H` ＝ヒント。

## 仕様メモ

- **お題は日替わり**：日本時間の日付をシードに、難易度別（初級→最終問題）の5プールから1通ずつ選ぶ。同じ日なら全国共通なので、Xでタイムを比べ合える。
- **親指年式の判定**は「その日のお題の最短打鍵数 ÷ タイム（打/秒）」で決める。日によってお題の長さが違っても公平になるように。7段階（1999年製〜2026年製）。
- 結果画面に「あと◯秒縮めると【次の年式】」を表示して、もう一回を促す。
- 「機種変更（0円）」でケータイの色をパールピンク／シルバー／ブラックに変更（結果カードにも反映）。
- 記録（今日のベスト・最高年式・受験回数・ミュート・機種色）は localStorage に保存。使えない環境でも遊べる。

## 技術メモ

- 完全静的（`index.html` / `style.css` / `app.js`）。ビルド・外部API・Cookieなし。外部リソースは Google Fonts（DotGothic16、M PLUS Rounded 1c）のみ。
- ケータイ、アイコン、OGP はすべて CSS / SVG / Canvas で描画（画像生成AIは不使用）。
- キーは `pointerdown` で即反応。`touch-action: manipulation`、`user-select: none`、`-webkit-touch-callout: none` と touchstart の抑止で、連打時のズーム・長押しメニューを防止。input 要素は使わないのでソフトウェアキーボードは出ない。
- 効果音は WebAudio で合成（キー音・送信音・着信音など）。最初の操作後に AudioContext を開始。ミュート状態は保存。
- 画面高さ 548px（iPhone SE の Safari）でも液晶とキーパッドが収まるように、高さ別にレイアウトを詰めている。スマホ横持ちでは「縦持ちでどうぞ」と表示。
- `prefers-reduced-motion` ではアニメーションを抑制。
- OGP 画像は `ogp-src.html` をヘッドレス Chrome で撮影し、Pillow で 256 色に減色して `ogp.png`（約 220KB）にしている。

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --hide-scrollbars \
  --window-size=1200,630 --virtual-time-budget=5000 \
  --screenshot="<保存先の絶対パス>\ogp-raw.png" "file:///C:/VS_codeX/claude-makase/keitai-uchi/ogp-src.html"
```

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（タイトル／検定本番／結果）とメタ情報 |
| `style.css` | ケータイ本体・液晶・キーパッドの描画とレイアウト |
| `app.js` | トグル入力、お題、判定、効果音、シェア、結果カード画像 |
| `ogp-src.html` / `ogp.png` | OGP 画像の元レイアウトと出力（1200x630） |
| `favicon.svg` / `apple-touch-icon.png` | アイコン |

※実在の検定・団体とは関係ありません。お題に実在のキャリア名・サービス名は使っていません。
